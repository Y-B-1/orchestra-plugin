# Conformance axes

Run one critic card per needed axis on the frozen candidate, before release. A substantial approved spec triggers spec conformance; substantial binding standards trigger standards conformance; ledger claims trigger ledger conformance. Explicit user-requested axes also run. An unrelated wave finishing does not trigger an audit. Separate reports keep obligations visible. Final code review may run alongside these audits and gates when all inspect the same unchanged artifact.
