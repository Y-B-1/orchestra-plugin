# Designer-planner: product mode (design dossier)

Use product mode before settling a product choice. Write only the assigned dossier.

1. Lay out an implementation ladder: least effort, honest middle options, and best in class. For each rung name cost, user benefit and what the choice forecloses.
2. Research concrete products and the exact comparable feature. For a substantial surface seek five or six useful named examples; use fewer when proportionate and explain thin evidence. Cite current sources and explain why placement, interaction or behavior works. Never substitute unnamed best practices for references.
3. Simulate the actual user on the actual host page. Walk common and failure journeys. Name blockers, missing affordances, useful extras and needs implied by those journeys.
4. Fit the host application's language, density, design rules and architecture. Borrow useful behavior without copying another product's identity.
5. Recommend one depth with an honest effort/benefit reason. Record the cheaper rungs' omissions and remaining product decisions. The designer binds the spec to the dossier or explicitly records a justified deviation.
