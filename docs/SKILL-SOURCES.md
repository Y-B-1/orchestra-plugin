# Skill sources: capability matrix for Orchestra v2

Card MX (PLAN-v2). Input to the S1 to S7 authoring tickets and to the cohesion review (SPEC-v2 8.4). Started from commit `512bfac2159ba9c3e680db5af621f379eef50be5` and checked against SPEC-v2 and PLAN-v2 at `d0370c1`. Built from the pinned upstream texts of RESEARCH-v2 I2 and the v1 Orchestra method files.

Skill curation is a synthesis. Each row takes a base text, merges in the stronger elements of the other sources, fills gaps with Orchestra text, and names the files that carry the result. Superpowers is the base wherever it has a candidate. Nothing upstream is copied: each skill file is new text in Orchestra vocabulary, written from its rows.

License notes:
- Every MIT source may be used at text level and is credited in `plugins/orchestra/THIRD-PARTY-NOTICES` with URL, full SHA and license text. A row that uses an MIT source only for an idea still credits it by `repo@sha12` in the destination's `Source:` header, so credit never depends on judging how close a paraphrase is.
- Idea-level sources (the Claude built-ins, and the Pocock `pr` skill, whose CREDITS.md attributes its method to a third party) appear in the header as `ideas: <name> (idea level)`. Their text is never copied.
- The Lens repo's TRADEMARK.md covers its mark in any casing, including inside the organisation and repository names. This document spells those names only inside citation coordinates and calls the source "Lens repo" elsewhere. Skill texts never use the mark; their `Source:` header carries the repository coordinates only, as the SPEC 8.2 grammar requires.

## Legend

- Upstream paths are relative to the pinned repository root (`repo@sha12:path`). "same dir:" lists sibling files of the path before it.
- `v1 X.md` means `plugins/orchestra/skills/orchestra/references/X.md` at `512bfac`, the existing Orchestra method text. It is part of the synthesis, not discarded.
- Destination cells list paths relative to `plugins/orchestra/skills/`, each in backticks. Every destination of a row whose License cell names an upstream or idea-level source carries a `Source:` header (SPEC 8.2, 8.3).
- "none" in a source column means the source has no candidate text for the row.
- License per element follows its source in the Sources table: an element from an MIT source is MIT text; an element marked "(idea level)" (the Claude built-ins, Pocock pr) is an idea whose text is never copied.
- Rejected holds only elements that conflict with Orchestra (the 8.2 avoid list, never-pause, personas, telemetry, a host feature subagents lack, the owner-trigger rule for the full suite, no delegation or user interaction inside workers) or add nothing.
- Worker limits used in rejections: workers have no Agent tool, no Skill tool and no user interaction; read-only roles have no Edit or Write.
