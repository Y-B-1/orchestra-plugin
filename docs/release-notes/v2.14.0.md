Orchestra 2.14.0 removes hand steps between a worker's report and an accepted card, and tells the coordinator what moved.

## What changed
- **Reports and the board:** a `SubagentStop` hook saves each worker's final message and records it as the report. A `board` line rides on card-moving commands, a `PostToolUse` hook delivers a pending change once, the prompt hook adds a line only when the board changed, and `Stop` blocks once outside autonomy while a card waits.
- **Fewer hand-built pieces:** `wave --emit` prints each card's `agent_call` and prompt; `card ID`, `ledger` and `package TASK` render the brief, the BUILD-LEDGER rows and a reviewer package from engine facts; `refusals` reads the refusal log.
- **Accepting work:** `accept` compares the reported commit and scoped evidence ignores commits outside a card's files. A builder report must answer every acceptance line; `accept --ruling TEXT` records a coordinator ruling on an unmet criterion; `report --accept` closes an inline card in one call. Refusals name the failing check or key.
- **Receipts:** `review --token` covers sibling lens cards and takes critic and repair_check receipts; `--defer-out-of-scope REASON` defers out-of-scope items. An empty `cleared` means none. Out-of-scope items on a non-final receipt are kept as notes, a loosening.
- **Runs and worktrees:** `start` returns `resume` per requeued card; the CLI refuses from a linked worktree; `worktrees` lists leftovers and prints removal commands; `report` refuses a commit on the wrong base. The autonomy ledger may set `- Repairs: up to N per chain`, and a sibling repair no longer waits on a parent reservation.
- **Guard:** a worker's `orchestra.py --lease` command is denied in every mode; the mod refuses an Orchestra spawn without a `Mode:` line.
- **Deferred:** F18, F21, `--lease @session`, engine-owned worktrees and four items found during the run (F38, F39, F40, F43). See [CHANGELOG.md](https://github.com/Y-B-1/orchestra-plugin/blob/v2.14.0/CHANGELOG.md).

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
