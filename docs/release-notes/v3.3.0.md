Orchestra 3.3.0 holds every engineering capability of mattpocock/skills and pstack, as good as or better than the source, and matches 3.2.0's speed.

## What changed
- **Full coverage of mattpocock/skills and pstack.** All 80 in-scope skills of the two packs are better or equal in Orchestra, checked by two independent audits and a third check on the released text. `docs/COVERAGE.md` lists each source skill, where Orchestra covers it and what loads it. Out of scope: prose style, video, personal recaps, a pack's own setup and help menus.
- **Two new situation skills.** `ship` for pull requests (red CI, review comments, conflicts, pre-commit hooks, git guardrails on request) and `verify` for driving the real app and flows with many states.
- **Grouped, not copied.** Each capability lives in the agent file, role skill, situation skill or reference file it belongs to; the routing table in the main skill decides when it loads, so a routine unit loads none.
- **First-time-right checks** from the owner's own rework patterns go into each builder brief they apply to: every sibling place for an "all" ask, every theme, bounded values that agree with their labels, stated windows, one check per rule, later corrections win, and no done claim while an ask is open.
- **Builders** write the failing test first, keep expected values independent of the code, mock only system boundaries, and read the types lens in typed code.

## Benchmark

It passed 99.3% of hidden tests and scored 96.0% on the blind rubric, the highest of the five arms. Details and limits: `docs/BENCHMARK.md`.
