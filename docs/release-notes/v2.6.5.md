Orchestra 2.6.5 hardens the autonomy pull request push.

## What changed
- **Push destination is checked, not only the settings:** `autonomy arm` records where each remote pushes to, using `git remote get-url --push`, which applies `pushurl`, `insteadOf` and `pushInsteadOf`. A pull request push is refused when that answer differs at push time. A changed remote URL or rewrite can no longer redirect an approved push, whichever setting or route caused it. The guarded-key list from 2.6.3 stays as the first line of defense.
- **Re-arm after updating:** a run armed under 2.6.4 or earlier has no record, so its pull request pushes are refused until the owner arms autonomy again.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`.
