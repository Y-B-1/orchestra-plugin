# Orchestra 3.5.0

Adds a mandatory test gate before every push, a leaner unit-test suite for this repository, and agentic e2e as the only e2e style. The purpose is unchanged: run every independent ask in parallel, at full quality and the lowest cost.

## Added
- **The test gate.** `lean.py gate` records the project's test runs per branch: `gate unit --full` is the one full unit run of a pull request and refuses a second; `gate unit --scoped` is the run for everything after it; `gate e2e` accepts only a scoped command (`--changed-since`, `--grep`, `--tag`, `--last-failed`, `--shard` or a test file) unless the owner sets `ORCHESTRA_E2E_FULL=1`; `gate skip unit|e2e REASON` is the honest record for a repo with no such runner; `gate status` must exit 0 before the push. Under `/orchestra:goal` the Stop hook does not end the goal until it does.
- **What the full run is.** The commands the project's CI runs (typecheck, lint, tests, build), run locally once. If the repo has `tsc-rs`, `tsrs` or `tsgo`, the typecheck uses it. These tools check types only; they do not run tests, so scoped reruns use the project's own runner (`vitest related`, `jest --findRelatedTests`, `pytest <paths>`, `go test <pkgs>`).
- **Lean tests.** `orchestra:test-quality` gains "Lean tests": one test per behavior, table-driven cases, pure functions called directly, shared fixtures, literal expected values. The pre-PR scan reports `test-count` when a branch adds more than 5 net tests; each added test must prove a behavior no existing test proves.
- **Agentic e2e only.** `orchestra:verify` gains `references/e2e.md`: tests are user paths written as arrange, act, assert with an ending `expect`, scoped by the Filters API (the Jev decision model skips tests a diff cannot affect), never run in full unless asked.

## Changed
- This repository's own tests: shared `tests/support.py`, table-driven rows, direct calls for pure rules, and a template repo copied per test instead of rebuilt. The suite runs in about half the time and checks the same behaviors (a 34-mutation probe killed every mutation the old suite killed).
- The e2e setup moved from `e2e` 0.18.0 to 0.23.0 with the decision filter. It needs Node 22.22.3 or newer, or 24.8 or newer. The example.com scaffold is removed; `tests/agentic/template.e2e.ts` is a skipped template. This repository has no web UI, so its real end-to-end check is `scripts/live-check.py`.

## Upgrade
Reinstall Orchestra from the marketplace and restart the client. A goal started before the upgrade has no gate record; run `gate skip` with a reason or one `gate unit --full` once.
