Orchestra 2.7.1 removes the dead ends in a run and keeps push URLs out of the state.

## What changed
- **Finish needs a review:** a run that changed files needs a current final review even with no cards.
- **Start baseline:** work already in the tree when a run starts is not counted toward its size or review lenses.
- **Fewer false stale results:** staging or committing reviewed work unchanged keeps whole-repo evidence current, and interpreter leftovers such as `__pycache__` never count as changes.
- **Recovery:** `start --recover --harness-session ID` takes back a lost lease; `cancel TASK --reason TEXT` drops a card that should never run; a worker that cannot do its card ends its report with `BLOCKED: reason` and the card is parked.
- **Credentials:** `autonomy arm` records a digest of each remote's push URL, not the URL. Re-arm after updating.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`.
