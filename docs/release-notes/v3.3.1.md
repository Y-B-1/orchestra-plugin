# Orchestra 3.3.1

A bug-fix release for `/orchestra:goal`.

## Fixed
- The goal's Stop hook no longer re-prompts in a loop. It stays quiet while a subagent or Workflow agent is running, because the app wakes the session when the worker finishes. It never sends the same prompt twice for work that has not changed; it shows one line and waits.
- The no-goal reminder about open asks follows the same two rules.

## Restored from 2.15
- A goal on a GitHub remote is done only once an open pull request holds the current head.
- Under a goal, a turn that ends with a question is told to decide, log it and continue.
- The main skill says how to wait: end the turn while workers run, do not poll, do not repeat a status, and check which workers still run after a resume.

## Upgrade
Reinstall Orchestra from the marketplace and restart the client. Goal files from 3.3.0 keep working.

## Checks
`scripts/check.sh` passes (unit tests on Python 3.11 and 3.13, strict plugin and marketplace validation). New tests cover each rule above.
