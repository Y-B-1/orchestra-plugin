Orchestra 2.15.0 makes autonomy work like a goal, runs each card where its model fits, and cuts the engine turns the coordinator needs.

## What changed
- **Autonomy keeps going like a goal:** an armed run nudges an idle board, a failing gate or a silent worker instead of stopping. On the third unchanged pass it parks the unfinished cards `needs-owner:escalated` and stops. While armed, a question with a "(Recommended)" option is answered by the hook and logged; an armed run also removes its merged clean worktrees and temp files.
- **Model fit:** hooks record the session model. A card on another model family, or a higher effort, starts only on a worker; `inline` refuses it.
- **Fewer engine turns:** `do` runs several commands in one call; `inline TASK --report FILE --accept`, `report --accept`, `finish --accept-reported` and chain accept close cards in fewer steps; `criterion` records your evidence on an unmet criterion; `status --brief` prints a compact summary; `own add` adds an owned path to a card.
- **`NOW.md`:** one short file in the state directory holds the present state of the run.
- **A tiny task starts no run:** edit, check and commit inline.
- **Lease and restart:** the coordinator keeps its lease after a restart of the same conversation. A forked session reads only until `start --recover --take-over`.
- **Clearer refusals:** a refused start names the blocking card and the cause. `waves` adds `wave_now` and `serialized`. A `"finalize": true` card waits for every other card.
- **Board pane:** the pane opens when autonomy arms and shows what needs you and what was decided for you.
- **Generator:** it refuses an unknown tool name and an oversized agent catalog.
- **Live matrix:** new scenarios `m1` and `s1`, and `--repeat N` to find flaky scenarios.
- **Repairs after review:** an armed run counts a silent worker as gone, so it nudges and escalates. `do` refuses `autonomy`, `permit` and `release` steps. The state-write check reads `>&1" "/../state.json` and the other quoted-delimiter forms as writes. An `rm` below the temp directory may carry a glob only in its last path component. A file a sibling card owns counts as that sibling's work only when the sibling's own commits made every change to it.

## Known gaps
- The state-write check reads `>&N` followed by a quote with its own quote tracker, which ignores `$'...'` escapes, `#` comments and heredoc bodies: a quote inside one of those can still hide a write such as `echo $'\'' >&1' '/../state.json`. The guard is best effort.
- Deferred review notes are listed in `docs/BUILD-LEDGER.md`.

## Native task tools
On Opus, Sonnet and Haiku 5.5, Claude Code withholds `TaskCreate`, `TaskUpdate` and `TaskList` unless the session starts with `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. Without it the board's task mirror stays off.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
