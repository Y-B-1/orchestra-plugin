Orchestra 2.12.0 removes the friction a coordinator met while using Orchestra to ship 2.11.0: fewer repeated reviews, fewer hand edits to review receipts, and merged-branch cleanup that works the way people write it. Nothing it changes lets work be accepted, or a command run, on less evidence than before.

## What changed
- **Repairs start from the finding you have:** a commit to unrelated files no longer makes a review finding too stale to start its repair. Acceptance still needs a current clean fix re-review.
- **One fix re-review, several chains:** a fix re-review that blames one repair no longer blocks the others it covers.
- **Red-first evidence counts:** a builder lists the failing run before its fix with `"expect": "fail"`, followed by the passing run of the same command.
- **Shorter commands:** `dispatch TASK` names the worker `orchestra-TASK` when you leave it out, and `review FILE --token TOKEN` records a final review and accepts its card in one step. A reviewer may write the artifact as `"<sha> clean"`.
- **Merged-branch cleanup:** a merged delete may start with `cd <path in this repository> &&` and end with a read-only `| tail`, `| head`, `| grep` or `| cat`. A cherry-picked or rebased branch whose changes are already on the default branch now counts as merged (each path it changed holds the same entry, mode and object, on the default branch).
- **Still open, by design:** resuming a run after an app restart ends it, a repair budget for unattended runs, and a recorded merge permit are proposals for the owner (docs/BUILD-LEDGER.md, 2.12.0).

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
