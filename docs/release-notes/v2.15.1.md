Orchestra 2.15.1 fixes friction from the 2.15 live run and closes the review notes 2.15.0 deferred.

## What changed
- **Model fit for every role:** a sized run checks the session model for every worker card, not only builders. `waves` adds `track`, the order the main session works the queue, and the board line, the pane and the native task list show it.
- **Escalation and take-over:** a card parked by escalation keeps its reason (`needs-owner:escalated (REASON)`). A plain `start` refuses a run owned by another session and names `start --recover --take-over`.
- **Review and checks:** `review --token` needs no report path; a final review survives a squash merge; a final review brief needs a `Lens:` line; an acceptance line that matches no test file is refused at `add`; a red-first check ignores one trailing note; a queued repair holds only its own files against another repair.
- **Finish:** `finish` refuses leftover worktrees; `gate` keeps the output of a killed command; a `pr` may be stacked on an open pull request of the previous run.
- **Guard:** cleanup removes only clean, merged worktrees on a branch the run made; temp and worktree `rm` globs are tighter; a refused push says its shape is the cause; a prompt ends an armed run past its deadline; the Stop nudge lists each silent worker as alive, gone or unknown.
- **Docs and code:** the README lists every command; `do "report W T F" "accept ID"` reports and accepts a worker card in one call; 2.15.0 wording that did not match the code is corrected in the changelog; dead reason tests and duplicate helpers are removed.
- **Tests:** the F89 timing tests compare against a benign twin and run with a 30 s per-test timeout.

## Known gaps
- Items deferred to the next release (F97 to F100) are listed in `docs/BUILD-LEDGER.md`.
- The state-write check from 2.15.0 still reads `>&N` followed by a quote with its own quote tracker; the guard is best effort.

## Native task tools
On Opus, Sonnet and Haiku 5.5, Claude Code withholds `TaskCreate`, `TaskUpdate` and `TaskList` unless the session starts with `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. Without it the board's task mirror stays off.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
