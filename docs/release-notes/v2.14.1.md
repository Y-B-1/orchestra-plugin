Orchestra 2.14.1 fixes three guard gaps found by the first live test of the installed plugin in real Claude Code sessions, and adds that test to the repository.

## What changed
- **Worker lease deny works live:** 2.14.0 denied an `orchestra:` worker's `orchestra.py --lease` command in unit tests, but in a live session the mod shortcut skipped the Python hook. The shortcut now sends that call to Python.
- **Engine state is protected from shell writes in every mode:** a redirect, `tee`, `rm`, `mv`, `cp`, `ln`, `truncate`, `dd`, `chmod` or `sed -i` into the run's state directory is denied in `minimal`, `normal` and `protect`. One stray `echo >> state.json` used to corrupt the run and lock the session. Outside an autonomy or unattended lock, the shell rule allows the coordinator notes the Write rule allows at the state root (`progress.md`, `standing-orders.md`), so `echo >> progress.md` works; `autonomy.md` and the other state files stay denied. The `>|` redirect and the `-t DIR` form of `cp` and `install` are denied too. A `cd` into the state directory keeps writes denied for the rest of the command, whatever `cd` follows. Reads and `orchestra.py` commands stay allowed.
- **`protect` allows the pull-request push:** a plain feature-branch push no longer needs a release permit, as under autonomy. Default and protected branches, the release target, force pushes and URL remotes stay denied.
- **`scripts/live-matrix.py`:** 16 scenarios across guard modes, autonomy, Agent, Workflow and worktree dispatch, report capture, the Stop block, the prompt board line, resume and install, run in real `claude -p` sessions. `--plugin-dir` tests a candidate before release. See docs/live-matrix.md.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
