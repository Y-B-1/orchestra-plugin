Orchestra 2.9.0 closes the smaller items left from the audit and guards the PowerShell tool.

## What changed
- **Shorter session start:** the run brief placed in a new session no longer carries empty sections.
- **Pull request pushes keep the branch name:** autonomy pushes `feat/x` to `feat/x` only. `HEAD:other-name` is refused with a reason, and a non-ASCII branch name has its own message.
- **Merged-delete check has a deadline:** 25 seconds in all. Past it the delete is denied with that reason.
- **PowerShell tool is guarded:** its commands are read with the Bash rules. Git, release and deploy commands are caught; PowerShell-only commands such as `Remove-Item` are not.
- **Windows gates:** a gate runs in a job object, so a process it leaves running is found and stopped.
- **Still open, by design:** a same-size rewrite of pre-run work is under-counted in the size estimate; files over 64 MiB are bound by size, mtime and samples; `core.filemode=false` with a staged-only chmod then a commit; the TypeScript module stays inert on Windows paths. Windows has not been run with Claude Code on a real machine.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`.
