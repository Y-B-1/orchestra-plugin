Orchestra 2.15.2 lets the main session run the main track and closes the friction left from 2.15.1.

## What changed
- **Model fit ranks families:** a session at or above a card's model family (opus, sonnet, haiku) runs the card inline; on the same family the effort decides. The policy key `model_fit` is `stronger` (default) or `exact`, the 2.15.1 rule. Track step 1 names only a card that can start inline now, else `wait: true`. Native task subjects renumber `step N` with the track.
- **`replace OLD TASKFILE`:** swap a queued, reported or parked card for a new one; dependencies and review targets move with it.
- **`resume ID`:** send a reported card back to its worker; the next report replaces the first.
- **Rulings and triage:** `accept --ruling` covers a failing check it names; an out-of-scope review item may be `deferred`, and a final receipt lists untriaged items as `needs_triage`.
- **Policy `full_check`:** a card that touches the listed paths needs a passing run of the listed command in its self-review.
- **Guard:** under autonomy `rm` below `claude-<uid>` is limited to one session's directory; `foo*.log` style globs in the temp directory are allowed again; Python caches do not block worktree cleanup.
- **Hooks:** a model switch passes its session id; a resumed worker's second report replaces the first; the restart note lists a gate with no receipt and worktrees with a live process.
- **Live matrix:** 22 scenarios. `t1` shows the main session running the main card inline while a worker ran a disjoint one; `a4` proves the scratchpad delete rule on a decoy temp tree.
- **Clearer next steps (F108 to F110):** a refused ruling names what to write; a reported code review card points to `review --token`; `add` warns while a final review runs.
- **Main session keeps moving:** a reported inline card no longer blocks the next inline start (F111); `resume` restarts the silence clock; `replace` waits for a running review of the old card.
- **Review fixes:** the acceptance check also reads prose outside code spans; rulings match whole words; the Model fit line skips review and tiny cards; the temp check ignores case; cleanup sees files inside ignored cache folders.
- **Docs:** 2.15.1 notes corrected: `rm -rf /tmp/*` is denied, escalation adds the original reason only to a card already parked without `needs-owner:`, and the command is `start`.

## Known gaps
- `t3` skips in headless runs (the board mod does not run under `claude -p`); native task renumbering is covered by mod unit tests only.
- The first prompt after cards are added by CLI shows no board line, and the session model reads unknown until the first `orchestra.py` call.

## Native task tools
On Opus, Sonnet and Haiku 5.5, Claude Code withholds `TaskCreate`, `TaskUpdate` and `TaskList` unless the session starts with `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`. Without it the board's task mirror stays off.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
