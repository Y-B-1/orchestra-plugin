Orchestra 2.10.0 makes autonomy visible and adds three review rules.

## What changed
- **Stop reason stays on screen:** after autonomy stops, the status band shows `stopped: <reason>` and how to re-arm, until you arm again, disarm or start a new session.
- **Richer band while active:** running background workers, stalls and a worker silent past the stale limit.
- **Idle on a lost worker:** the check that stops a stalled run only runs when a turn ends, so a session waiting on a dead worker was never checked. The band now names the silent worker; the engine still decides nothing without a Stop event.
- **Review and critic rules:** judge against HEAD, name every added suppression, read the rules from the base commit; own each worker result; prove or report `unproven` the facts a change's safety rests on.
- **Packaging:** no duplicate version in the marketplace entry, an icon, CI on Claude Code 2.1.306.
- **Still open, by design:** the items listed in the 2.9.0 notes. Windows and macOS have not been run with Claude Code on a real machine.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
