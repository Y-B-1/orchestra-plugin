Orchestra 2.8.1 fixes the Windows failures that the first Windows CI run found in 2.8.0.

## What changed
- **Windows state writes:** the engine opened the state directory to flush it to disk, which Windows refuses, so every state write failed. It now skips that step on Windows.
- **Autonomy cleanup:** `git worktree remove C:/path/to/worktree` is accepted as a plain cleanup command.
- **Windows CI:** the full test suite now passes on `windows-latest`, in three shards. Tests that assumed POSIX now use the portable lock layer or are skipped on Windows.
- **Still unconfirmed:** Windows has not been run with Claude Code on a real machine; treat it as supported by CI, not yet field-tested.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`.
