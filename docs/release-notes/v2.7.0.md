Orchestra 2.7.0 narrows the guards to autonomy runs and makes the hooks fail closed.

## What changed
- **Config guard only under autonomy:** changing Git aliases, push mappings, remotes and credential settings is denied while autonomy runs and is an ordinary command otherwise. 2.6.3 to 2.6.5 denied it for everyone.
- **Fail closed:** a crash in the PreToolUse hook, or a missing home directory, denies the call and names the cause. State falls back to a per-user temp directory without a home.
- **Ledger lock:** while autonomy is active an agent cannot edit `autonomy.md` or run `autonomy arm|disarm`, and `arm` refuses when already armed. This closes a way for an agent to rewrite its own boundaries.
- **Sessions:** a run bound to another session no longer locks a second session in the same repository out of Agent calls.
- **Unreadable state:** the denial names the file and `start --new-run`, which keeps the old file under `history/`.
- **Speed:** commands with many heredocs are classified in one pass.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`.
