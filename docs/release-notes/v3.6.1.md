# Orchestra 3.6.1

Follow-ups from the 3.6.0 run, and the fixes from the first CI run on every platform.

## Added
- **`lean.py owns COMMIT|A..B -- PATH...`.** Exits 0 when every file the commit changed is inside the unit, 1 with one line per file outside it, and 2 for a bad commit, an empty range or no paths. A path is a file, a folder (with or without a trailing `/`) or a glob where `**` crosses folders. It reads commits, so it does not see an uncommitted edit. `orchestra:orchestra` runs it on every commit a builder reports.
- **A wizard template.** `skills/orchestra/references/wizard-template.sh`: copy it, fill the STAGES part and leave the library alone. It asks for secrets without showing them, writes a private `.env`, and skips every command passed through `run` when `DRY_RUN=1`.

## Fixed
- **Windows: the test gate.** The liveness check of a claim sent Ctrl+C to the console, and the gate's file lock did nothing, so two full runs could start together. Both are fixed in the new `scripts/procs.py`.
- **Windows: the guard.** A `git -C` command with a backslash path is now followed to that checkout. A backslash escape is not understood on Windows; `docs/hooks.md` says so.

## Changed
- **Packing.** A file and the file that mirrors its rule go in the same unit.
- **Release documents** are written after the review is clean, from the diff, and join one light re-review.

## Checked
- CI passed on Ubuntu (Python 3.11 and 3.13), macOS and Windows.
- Agent files with a model family resolve to that family under a different main model: a session on Haiku ran its Sonnet and Opus agents on Sonnet and Opus. `critic-fable` was not started.

## Upgrade
Reinstall Orchestra from the marketplace and restart the client.
