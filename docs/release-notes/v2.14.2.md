Orchestra 2.14.2 fixes the coordination friction found while building 2.14.1 with Orchestra itself, and closes the guard gaps its reviews found.

## What changed
- **Workflow reports are captured again:** Claude Code now puts a relayed copy of the user's request first in a Workflow agent's transcript. Capture now finds the `Assignment:` line in a later user message, so Workflow builders' reports are recorded without a manual `report`.
- **The board names only cards `accept` takes:** the Stop hook and the prompt board line no longer suggest accepting a card that waits on a repair, a running review or a failing self-review.
- **A second repair needs the owner's words:** a repair of a held chain carries `owner_approval` with the owner's quoted text, logged in `progress.md`.
- **`finish` after a clean fix re-review** works without an extra final review.
- **Clearer refusals and tolerant receipt fields:** refusals name the next step; a review artifact with a parenthesised note and gate receipts with prose around the id record.
- **State-write guard gaps closed:** `>&FILE`, subshell and group `cd`, `pushd`, `builtin cd`, `touch`, `mkdir` and `cp -r` into the run state are denied.
- **Gate order:** the mod tests run before the unit suites, so they no longer time out under load.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
