Orchestra 2.13.1 lets a run finish after its pull request is squash-merged.

## What changed
- **`finish` works after a squash merge:** 2.13.0 refused to finish a run whose work reached `main` through a squash merge, with "Accepted work is not in HEAD", because a squash commit hides the builders' commits from both the ancestor check and `git cherry`. A reported commit now also counts as landed when a commit the engine itself gated or reviewed contains it, and `HEAD`'s last 50 first-parent commits hold a commit with that commit's tree, or with its whole patch from their merge base. Work that never merged is still refused. The board's landed marks use the same rule.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`. To receive releases on their own, open `/plugin`, go to Marketplaces, select `orchestra-distribution` and choose Enable auto-update.
