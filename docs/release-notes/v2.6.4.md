Orchestra 2.6.4 changes documentation only. The plugin code is the same as 2.6.3.

## What changed
- **Validation record:** `docs/BUILD-LEDGER.md` and `docs/VALIDATION.md` now record the live checks run against the published 2.6.3 release: install from GitHub, the `deadline` stop, `clear` and `resume` rebinding, and the large route with one repair ending in `hold`.
- **Still not performed:** a real GitHub pull request opened by an unattended run, macOS, and a model-driven repair or hold.

## Install

```sh
claude plugin marketplace add Y-B-1/orchestra-plugin
claude plugin install orchestra@orchestra-distribution
```

Already installed: `claude plugin marketplace update orchestra-distribution`, then `claude plugin update orchestra@orchestra-distribution`.

Full history: [CHANGELOG.md](https://github.com/Y-B-1/orchestra-plugin/blob/v2.6.4/CHANGELOG.md).
