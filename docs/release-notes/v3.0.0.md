Orchestra 3.0.0 is a rewrite for speed on prompts that hold more than one ask.

## What changed
- **One skill, five agents, one command, three hooks.** The coordinator skill writes an ask ledger, plans only what is new, runs every independent unit at once in one Workflow, and reviews the finished work once. Builders check and commit their own units.
- **`/orchestra:goal`.** A Stop hook keeps the session working until every ask in the ledger is done or dropped with a reason, the changes are committed and the branch is pushed. It gives up after 60 continuations, and `lean.py goal stop REASON` ends a goal that only the owner can unblock.
- **One guard.** Only merging into the default branch is denied: `gh pr merge`, `gh api` merge calls, pushes to the default branch, and force pushes or deletes of it. Everything else runs.
- **State is a file.** The ask ledger and the goal live in `.git/orchestra/`.
- **Removed:** the card engine, autonomy mode, the board mod, guard modes, size tiers, eight role skills and twelve agents. A benchmark showed the smaller design delivers the same quality about twice as fast as plain Claude Code; see `docs/BENCHMARK.md`.

## Upgrade
Finish or interrupt any active 2.x run with the 2.x plugin first. The 2.x run state is no longer read. Reinstall from the marketplace and restart the client.

## Checks
`scripts/check.sh` (unit tests on Python 3.11 and 3.13, strict plugin and marketplace validation) and `python3 scripts/live-check.py` (three real headless sessions) both pass.
