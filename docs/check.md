# lean.py check

`python3 lean.py check [--base REF] [--max-lines N] [--json]` scans the diff of the current branch against its base and prints one line per finding: `KIND path[:line] message`, grouped by kind, then a summary line. The base is always a merge base: with `--base REF` it is `git merge-base HEAD REF` (REF itself only if there is none), else with `origin/<default branch>`, else with the local default branch. The first output line names it: `base <sha> (how chosen), N files, +A -R lines`. Two git calls read the whole diff, and the user's `diff.external`, textconv and `interHunkContext` config are ignored. It compares the working tree, so committed, staged, unstaged and untracked (not ignored) files are all included. It never blocks: it exits 0, or 2 for invalid arguments or when no base is found (no merge base, or a `--base` that does not exist). It reads git output as bytes (invalid UTF-8 is replaced, paths with quotes or spaces work), resolves the repository root once so the result is the same from any subdirectory, and follows renames: a pure rename adds no lines and is compared with its old path. The coordinator and the reviewer read it before review. `--json` prints `{"base", "how", "files", "added", "removed", "findings", "counts"}`.

**size** A text source file is over the line budget (default 500) and grew in this diff. A file already over budget that did not grow is not flagged. Lockfiles (`*.lock`, `pnpm-lock.yaml`, `go.sum`, shrinkwrap), `*.min.*`, `dist/`, `build/`, binaries, generated files and prose or data files (`.md`, `.txt`, `.json`, `.yaml`, `.sql`) are skipped. A file is generated when a comment in its first 5 lines says so (`@generated`, `generated by`, `is generated`, `auto-generated`, `do not edit`); a passing mention of the word does not count. Split the file, or add a line `path-glob reason` to `.orchestra/budget-waivers` and say why in the report.

**test-weakened** The diff adds a skip or `.only` (in test files), a lint or type suppression (`eslint-disable`, `@ts-ignore`/`@ts-nocheck`, `noqa`, `type: ignore`, `pylint: disable`, `pragma: no cover`, `biome-ignore`, `nolint`; `xit`/`fit`, pytest `skip`/`xfail`, `skipTest`, Go `t.Skip`, Rust `#[ignore]`, Java `@Disabled`; a suppression that only moved is not new), a raised test timeout (an added timeout is compared only with a removed line that is the same apart from the number, so a new test with a long timeout is not flagged), deletes a test file or removes more assertions than it adds, or changes a snapshot, a CI workflow or a lint, type or test config (ruff, mypy, pytest, coverage, eslint, tsconfig, biome, vitest, jest, playwright, pre-commit, GitLab or CircleCI, `scripts/check.sh`). A rename is judged under its old and new name. Other languages' test configs are not watched. Each needs a stated reason in the report; otherwise undo it and fix the cause.

**self-mock** A test mocks a module of this repo (a relative or `@/`, `~/`, `src/` `vi.mock`/`jest.mock`/`doMock` path,  or a `patch`, `patch.object` or `monkeypatch.setattr` of the repo's own modules, found at any depth). That test then proves the mock, not the code. Use the real module and mock only the outside world.

**debug** Leftover `console.log(`, `debugger`, `console.debug(`, `breakpoint()`, `pdb.set_trace`, `[DEBUG-` or a Python `print(` that mentions DEBUG. Remove it before the PR.

**rules** The diff changes `AGENTS.md`, `CLAUDE.md`, `CONTEXT.md` a file under any `.claude/` or `.agents/`, Cursor or Copilot rules, `docs/AGENT-MEMORY.md` or `.orchestra/budget-waivers` (a waiver hides a size item, so adding one is reported). The reviewer judges the change against the base version of those rules, not the edited one.

**sensitive** A changed path names (plurals and camelCase words count, e.g. `payments/`, `authMiddleware.ts`) auth (also authorization, authz; not author), oauth, jwt, csrf, rbac, acl, login, signin, signup, session, token, secret, password, credential, payment, billing, stripe, permission, role, policy, security, encryption, admin, crypto, webhook, `.env`, middleware, migrations, `.sql` or `.prisma`. The reviewer loads the security lens for this change.

**secret** An added line looks like a credential (AWS key, private key header, GitHub `gh?_` token, `sk-`, Stripe live, `whsec_`, Slack, Google `AIza`, npm token; not JWTs or URL passwords). Only the path and line are printed, never the value. Remove it, rotate the credential, and keep it out of history.
