# lean.py check

`python3 lean.py check [--base REF] [--max-lines N] [--json]` scans the diff of the current branch against its base and prints one line per finding: `KIND path[:line] message`, grouped by kind, then a summary line. The base is `--base`, else the merge-base with `origin/<default branch>`, else with the local default branch. It compares the working tree, so committed, staged, unstaged and untracked (not ignored) files are all included. It never blocks: it exits 0, or 2 for invalid arguments or when no base is found (no merge base, or a `--base` that does not exist). It reads git output as bytes (invalid UTF-8 is replaced, paths with quotes or spaces work), resolves the repository root once so the result is the same from any subdirectory, and follows renames: a pure rename adds no lines and is compared with its old path. The coordinator and the reviewer read it before review. `--json` prints `{"base", "findings", "counts"}`.

**size** A text source file is over the line budget (default 500) and grew in this diff. A file already over budget that did not grow is not flagged. Lockfiles, `*.min.*`, `dist/`, `build/`, binaries and generated files are skipped. A file is generated when a comment in its first 5 lines says so (`@generated`, `generated by`, `is generated`, `auto-generated`, `do not edit`); a passing mention of the word does not count. Split the file, or add a line `path-glob reason` to `.orchestra/budget-waivers` and say why in the report.

**test-weakened** The diff adds a skip, `.only`, a lint or type suppression, a raised test timeout (an added timeout is compared only with a removed line that is the same apart from the number, so a new test with a long timeout is not flagged), or changes a snapshot, a CI workflow or a lint or type config. Each needs a stated reason in the report; otherwise undo it and fix the cause.

**self-mock** A test mocks a module of this repo (a relative `vi.mock`/`jest.mock` path, or a `patch` of the repo's own package). That test then proves the mock, not the code. Use the real module and mock only the outside world.

**debug** Leftover `console.log(`, `debugger;`, `breakpoint()`, `pdb.set_trace`, `[DEBUG-` or a Python `print(` that mentions DEBUG. Remove it before the PR.

**rules** The diff changes `AGENTS.md`, `CLAUDE.md`, `CONTEXT.md` or a file under `.claude/`. The reviewer judges the change against the base version of those rules, not the edited one.

**sensitive** A changed path names (plurals and camelCase words count, e.g. `payments/`, `authMiddleware.ts`) auth, oauth, login, session, token, secret, password, payment, billing, permission, role, crypto, webhook, `.env`, middleware or migrations. The reviewer loads the security lens for this change.

**secret** An added line looks like a credential (AWS key, private key header, GitHub, `sk-` or Slack token). Only the path and line are printed, never the value. Remove it, rotate the credential, and keep it out of history.
